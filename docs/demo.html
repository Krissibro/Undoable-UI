UndoableUI Demo

This page demonstrates UndoableUI, a library which adds undo and redo support to ordinary web pages. Instead of each input managing its own history, UndoableUI keeps a shared undo history across the page, so edits feel consistent and predictable. It also adds undo support to input types that don’t normally have it, like radio buttons, checkboxes, and color pickers. Try changing values below and use undo/redo to move back and forth through what you did. You can also adjust settings live to see how different undo behaviors affect the experience.

Ctrl + Z to undo
Ctrl + Shift + Z or Ctrl + Y to redo
